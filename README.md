# Baloo Virtual Assistant

Welcome to the Baloo Virtual Assistant project! Baloo is an AI-powered assistant designed to provide sassy, funny, and helpful responses. This project encompasses a chat interface where users can interact with Baloo for various tasks and inquiries.

## Features

- **Chat Interface**: A user-friendly chat window where users can type in their queries and receive responses from Baloo.
- **Responsive Design**: Ensures a great experience across various devices and screen sizes.
- **Personality-Driven Responses**: Baloo isn't just any assistant; it's programmed to be humorous, slightly impatient, but incredibly cute and helpful.

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenAI's GPT-3 (for AI responses)

## How to Use

1. Open the Baloo Virtual Assistant in your web browser.
2. Type your question or command in the chat input box.
3. Press Enter or click the 'Send' button to submit your query.
4. Enjoy Baloo's unique responses!

## Installation

This project doesn't require any special installation. Just clone the repository, and open the `index.html` file in your browser to start chatting with Baloo.
